# Project A - Exploratory Data Analysis on Iris Dataset

## Objective
Perform exploratory data analysis on the Iris dataset and identify patterns in flower measurements.

## Work Done
- Loaded and inspected the dataset
- Checked missing values
- Generated descriptive statistics
- Analyzed species distribution
- Calculated average measurements by species
- Created visualizations for species distribution and petal measurements

## Technologies
Python, Pandas, Matplotlib

## Run
```bash
pip install -r requirements.txt
python iris_eda.py
```
