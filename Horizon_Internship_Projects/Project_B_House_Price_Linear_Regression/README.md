# Project B - House Price Prediction using Simple Linear Regression

## Objective
Predict house prices from house area using Simple Linear Regression.

## Work Done
- Loaded house price data
- Split data into training and testing sets
- Trained a Linear Regression model
- Evaluated the model using MAE, RMSE and R2 score
- Predicted a sample house price
- Visualized the regression line

## Technologies
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## Run
```bash
pip install -r requirements.txt
python house_price_prediction.py
```

## Note
The included CSV is a small practice dataset created for the internship project demonstration.
